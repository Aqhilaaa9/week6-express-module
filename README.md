## Deskripsi 
program ini merupakan aplikasi web sederhana menggunakan Express.js yang berjalan di port 3000. Aplikasi ini memiliki beberapa route, yaitu route utama / yang menampilkan nama dan NIM, serta route /hitung yang menyediakan operasi matematika dasar seperti penjumlahan, pengurangan, perkalian, dan pembagian dengan nilai statis yang sudah ditentukan. Selain itu, terdapat route /profile yang dihubungkan dengan profileRouter, di mana data profil mahasiswa (NIM, nama, jurusan, dan angkatan) dapat ditampilkan semua dalam bentuk JSON atau ditampilkan berdasarkan NIM tertentu, dan jika NIM tidak ditemukan maka server akan mengembalikan pesan error 404.
